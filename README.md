# 홍보야 — 크리에이터의 미니홈피 · 미니샵 · 셀프 홍보 플랫폼

## 메인페이지

`index.html`은 생산자·메이커·콘텐츠·로컬 크리에이터를 위한 반응형 메인입니다.
분야별 필터, 검색, 미니홈피 예시, FAQ와 스튜디오 진입을 제공합니다.
메인의 카드는 명시된 디자인 예시이며 실제 판매자 목록이 아닙니다.
기존 아이템 화면은 `gallery.html`에서 이용할 수 있습니다.

브라우저 확인: Playwright와 Edge가 설치된 환경에서
`node test_home_browser.cjs http://127.0.0.1:8000/`

## 미니홈피 · 미니샵 (2026-11-05)

`mini.html`에서 프로필, 색상 테마, 쇼핑몰/SNS 링크(8개), 상품(12개)을 등록하고
미리보기·순서 변경·백업·공유를 이용할 수 있습니다. 구매는 연결된 외부 판매처에서 진행됩니다.

- GitHub Pages: 회원 서버가 없어 **기기 저장 모드**로 작동합니다. 공유 URL의
  fragment에 공개 프로필만 담아 다른 브라우저에서 복원합니다. 수정하면 새 링크를 공유해야 합니다.
- Python 서버: 이메일 가입, PBKDF2 비밀번호 해시, HttpOnly 세션 쿠키,
  소유자 전용 프로필 수정, 공개 프로필 조회를 제공합니다. 이메일은 공개 프로필에 포함되지 않습니다.
- 공개 회원 서비스 운영을 위해서는 Python API의 HTTPS 배포와 도메인 연결이 필요합니다.
  현재 로컬 서버는 이 PC에서만 접속됩니다. 이메일 인증/비밀번호 재설정은 구현되어 있지 않습니다.
- SNS 링크 연결은 외부 채널로 이동하는 방식입니다. SNS 자동 게시나 결제를 수행하지 않습니다.
- 미니홈피별 SNS 미리보기 카드(OG)는 정적 호스팅에서 개별 생성되지 않습니다.

## 온라인 공유 미리보기

- 공유 링크: https://mango7557-ui.github.io/hongboya-platform/
- 소스 저장소: https://github.com/mango7557-ui/hongboya-platform

GitHub Pages는 화면 확인용입니다. 등록·수정한 내용은 해당 브라우저의
localStorage에만 저장되며 다른 방문자와 공유되지 않습니다. 공용 상담 접수와
회원 데이터 수집을 위한 운영 서버는 별도 배포가 필요합니다.
로컬 실행에서는 아래 Python 서버와 SQLite를 사용합니다.

`python build_pages.py`로 `docs/`를 갱신한 뒤 `main`에 push하면
GitHub Pages가 해당 폴더를 자동 게시합니다.
이미지 업로드 키는 브라우저의 `imgbb_api_key` 설정값을 사용합니다.

## 로컬 실행 (홍보야)

Python 3.10 이상에서 `start.bat`을 더블클릭하거나 이 폴더에서 실행합니다.

```sh
python server.py
```

- 메인: http://127.0.0.1:8000/
- 관리자: http://127.0.0.1:8000/admin.html
- AI 상담: http://127.0.0.1:8000/chatbot.html
- 회원 가입: http://127.0.0.1:8000/register-bot.html
- 포트 변경: `python server.py --port 8080`

로컬 서버는 기존 화면의 `tables/*` API(조회·등록·수정·삭제, 검색, 정렬,
페이지 나누기)를 제공하며 `data/hongboya.sqlite3`에 데이터를 영구 저장합니다.
백업 시 서버를 종료하고 이 파일을 복사하세요. 서버는 이 PC에서만 접속됩니다.

ZIP에는 원본 서비스의 DB 데이터가 포함되어 있지 않으므로 최초 데이터는
비어 있습니다. 관리자 페이지에서 브랜드·포스터·배너를 등록하거나 기존
엑셀/CSV 자료를 업로드하세요. 아래의 기존 기능 설명에 등장하는 등록 데이터는
ZIP에 포함된 데이터가 아닙니다.

외부 이미지·CDN 사용에는 인터넷이 필요하며 AI 응답, 이미지 업로드 및
카카오 기능에는 해당 서비스의 유효한 API 키 설정이 필요합니다.

검증: `python -m unittest -v test_server.py`

## 🧠 AI 챗봇 학습 방식

### 자동 학습 (포스터 데이터 기반)
1. **가맹비용** (`franchise_csv`): CSV 파싱 → 항목명·금액·비고 구조화 → Gemini 시스템 프롬프트
2. **매장정보** (`store_info_url`): CSV 파싱 → 매장명·주소·전화 구조화 → 시스템 프롬프트
3. 구글 시트 URL이면 fetch → 텍스트로 변환, 직접 CSV면 그대로 사용
4. 챗봇 오픈 시 **캐시 무효화** → 최신 데이터로 재로드

### 프랜차이즈 필터링 (chatbot.html)
- **조건**: `franchise_csv` AND `store_info_url` 둘 다 입력된 브랜드만 학습 대상
- 두 항목 중 하나라도 없으면 자동 제외
- 상태바에 "프랜차이즈 브랜드 X개 / 비가맹 Y개 제외" 표시

### 수동 학습 (관리자 등록)
- **Q&A 입력**: 키워드 → 응답 직접 작성
- **자유형 입력**: 브랜드 소개·FAQ 등 긴 텍스트
- **구글 시트 연동**: A열=키워드, B열=응답 형식의 시트 CSV URL

### 구글 시트 CSV URL 형식
```
https://docs.google.com/spreadsheets/d/[시트ID]/export?format=csv
```

  └─ buildMainChatSystemPrompt(brandFilter)
